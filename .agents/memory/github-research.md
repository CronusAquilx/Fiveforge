---
name: GitHub research vs. app connection
description: How GitHub should be used while developing Forge Studio.
---

For Forge Studio, “look at GitHub” means search public repositories and workflows for implementation references; it does not by itself request a GitHub connection or GitHub UI inside the app.

**Why:** The user clarified that they meant web research, not an app integration.

**How to apply:** Use public repository research when helpful. Add live GitHub connection features only when the user explicitly requests them and specifies what the app should consume.
